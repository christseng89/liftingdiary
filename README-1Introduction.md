# 👉 **课程目的** & 👉 **使用的工具与技巧**

---

## 一、本课程的目的（Course Objectives）

本课程的核心目标**不是单纯完成一个应用**，而是让学员在「**真实复杂度**」的项目环境中，**掌握并精通 Claude Code 的实际使用方法**。

具体目的包括：

### 1️⃣ 深入理解 Claude Code 的工作方式

* 学会如何与 Claude Code 协作，而不是只把它当成「写代码工具」
* 理解 **System Prompt / Context Engineering** 对输出结果的决定性影响
* 学会通过结构化输入，让 Claude Code 产出**可控、稳定、可维护**的代码

### 2️⃣ 掌握在真实项目中的 Claude Code 应用技巧

* 在一个具备 **多层架构、真实业务逻辑、数据库关系** 的 Next.js 项目中使用 Claude Code
* 学会应对「不是 Demo、而是**接近真实生产环境**」的复杂度
* 提升 Claude Code 在复杂项目中的**一致性与可预测性**

### 3️⃣ 学会用工作流与自动化放大 Claude Code 的价值

* 不只是单次对话，而是通过 **Workflows、Subagents** 让 Claude Code 成为长期协作的开发伙伴
* 将 Claude Code 融入日常开发流程（**开发、修复、部署**）

### 4️⃣ 建立可复用的 AI 开发方法论

* 学会一套可以复制到**其他项目**的 Claude Code 使用模式
* 为未来更大规模、更复杂的系统（企业级、团队级）打下基础

## 二、本课程使用的工具与技术（Tools & Techniques）

### 🧠 AI / 智能编程相关

* **Claude Code**

  * 核心开发工具
  * 负责生成、修改、重构整个项目的代码
  * 贯穿课程始终

* **Context Engineering / Prompt Engineering**

  * 通过文档、规范、上下文来「约束与引导」Claude Code 的输出
  * 避免随机性与不可控行为

* **SubAgents（子代理）**

  * 为不同职责建立专用角色（如：架构、数据库、前端、测试）
  * 提升复杂任务的稳定性与可维护性

* **Custom Slash Commands**

  * 定义快捷命令来触发特定工作流
  * 提升开发效率与一致性

---

### ⚙️ 工作流与自动化

* **Custom Workflows**

  * 将多步骤开发流程自动化（如：新增功能、修复 Bug、重构模块）
  * 降低重复劳动

* **Claude Code GitHub Actions**

  * 在 GitHub 中自动分析并修复问题
  * 将 AI 直接纳入 CI/CD 流程

---

### 🗄 数据与后端相关

* **MCP（Model Context Protocol）**

  * 用于数据库初始化（Seeding）
  * 生成示例数据，方便开发与测试

* **关系型数据库设计**

  * 数据规范化（Normalization）
  * 多表关联（Relations）
  * 真实业务模型建模

---

### 🌐 前端与平台技术

* **Next.js**

  * 全栈 Web 应用框架
  * 支持 SSR、路由、API 等

* **Clerk**

  * 用户注册、登录与身份认证

* **Vercel**

  * 应用部署平台
  * 支持 Preview Branch / Preview URL
  * 实时查看 Claude Code 自动修复与更新的结果

---

## 三、课程完成后你将具备的能力

完成本课程后，你将能够：

* ✅ 在复杂项目中**稳定、高效地使用 Claude Code**
* ✅ 设计可控的 Prompt / Context，而不是「靠运气生成代码」
* ✅ 将 AI 编程工具整合进真实的开发与部署流程
* ✅ 建立属于你自己的 **AI + 软件工程工作模式**
